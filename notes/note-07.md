2 Simple Reflex Agents
These agents select actions based solely on the current percept,ignoring history(vaccum agent is
an example).seeing about efficiency it have smaller program size compared to a vast look up table
due to ignoring percept history.this is based on the condition-action rules.the agent can generate
actions based on abstracted state descriptions.these have certain limitations like these are only
effective in fully observable environments,partial observavility can lead to incorrect actions and
infinite loops(like vaccum agent with dirty sensor).randomization can help escape infinite loops by
randomizing actions, may perform better in certain situations but is generally less efficient than more
sophisticated agents.overall while simple reflex agents are straightforward, they lack the intelligence
and adaptability needed for complex environments.
3 Model-Based reflex Agents
These maintain an internal state to track to track unobservable aspects of the environment and also
update internal state based on perept history.intermnal state helps handle partial observability by


keeping relevant information (e.g., previous frames for detecting braking).the knowledge requirements
for this type are transition model(describes how the world changes due to the agents actions and
external factors) and sensor model(which relates the state of the world to the agents).it functionality
is to combine current percept with internal state to update the state description and the function

cannot determine the exact current state in partially observable environments.instead, they provide a
"best guess" of the current state based on available information.
4 Goal-Based Agents
These agents use urrent state information along with goal information to determine actions.here
goal represent desirable situations,like reaching a specific destination the action selection of these
agents can be straightforward(one action achieves the goal) or complex(requires considering multiple
actions), invloves planning and search to find action sequences to meet goals.the decision making
of these goal based agents are it considers future consequences of action("what will happen if i
do this?"),unlike reflex agents, goal based agent understand the reasons behind their actions(for an
example braking to avoid collisions).these are more adaptable than reflex agents,changing goals
is simple and doesnt require rewriting rules.reflex agents need all rules replaced for different
destinations, while goal-based agents only need a new goal specified.
5 Utility-Based Agents
These agents go beyond simple goals by incorporating a utility function that measures the desir-
ability of different states,utility allows comparison of actions based on factors like speed, safety,
and cost, rather than just binary goal achievement. utility function is like that it internalizes the
performance measure to maximize rational decision-making,facilitates handling conflicting goals and
uncertain outcomes. these agents choose actions that maximize expected utility based on probabilities
of outcomes and their respective utilities.this approach allows for rational decisions in uncertain
environments.this is designed to manage partial observability and nondeterminism.they require mod-
eling of the environment and decision-making algorithms but, building rational utility-based agents
is complex, involving research on perception, reasoning, and learning.Perfect rationality is often
unachievable due to computational limitations.
