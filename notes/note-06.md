3 Nature of Environment
In this first we will see what is task environment:which just simply the tasks or problems in the
environment that the agent aim to solve them.we will specify the tasks of environments into the


PEAS, which means, performance measure,environment,actuators,sensors.we can feel this through
the self driving car example.Now lets see the properties of the task environments, in which we
will see the different flavours of tasks environments.1.fully observable vs partially observable,fully
observable is that it can observer the complete environment and partially observable cant (like self
driving car and vaccum cleaner). 2.single agent vs multi agent in which single agent is the one
which operates independently in an environment, focusing on its own goals and decision-making
processes without collaboration or competition, multi agent is the one which involves multiple agents
interacting within a shared environment, which can lead to cooperation, competition, that influence
each agents behavior. 3.deterministic vs non-deterministic in which in a deterministic system, the
outcome of an action is predictable and consistent,the same input will always produce the same
result, allowing for precise planning and execution.whereas in a a non-deterministic system, the
outcome can vary even with the same input, introducing uncertainty and variability in actions and
results, making it challenging to predict behavior. 4.episodic vs sequential, in episodic tasks,the
agents experiences are divided into distinct, independent episodes, where each episodes outcome
does not affect future episodes, allowing for isolated decision-making.whereas in a sequential tasks,
each action affects subsequent states, meaning that the agents decisions are interdependent and must
consider the long-term consequences of its actions. 5.static vs dynamic environments, in a static
environments, the conditions remain constant while the agent is making decisions, the environment
does not change in response to the agents actions. whereas in a dynamic environments, conditions
can change while the agent is operating, often due to external factors or other agents, requiring
real-time adaptations and continuous assessment. 6.discrete vs continuous, in which we can observe
that in discrete environments, the tasks space is countable, consisting of distinct, separate values
or events, making it easier to analyze and manage using defined actions and outcomes. where
as in continuous environments, the tasks space is infinite and uncountable, allowing for smooth
transitions between states, which requires more sophisticated modeling and control techniques.
7.known vs unknown, in which we will see that in a known environment, the agent has complete
information about the environments states, actions, and outcomes, enabling it to make informed
decisions based on predefined rules and knowledge.whereas in a unknown environment, the agent
lacks full information, requiring it to explore and learn from interactions to gather data and adapt its
strategies over time.At last we can observe that a complex environment is the one which is partially
observable,multi agen,mnon deterministic,sequential,dynamic environment,continous and unknown.
